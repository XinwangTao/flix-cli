范围内

  • flixcli↔flixcli Windows 局域网一对一
  • 观看、可选单向音频、会话级有限鼠标/键盘
  • GUI / CLI / MCP 状态和撤销

范围外

  • 官方 Flix WebRTC 互通
  • 公网中继/NAT 穿透、无人值守控制
  • 任意远程命令、安全桌面绕过、多方会议
主路径：请求 → 认证 → 批准 → 连接 → 运行 → 撤销红色虚线：拒绝、错误或降级控制默认关闭，view/audio/control 分开批准

发起端 GUI / CLI

发起观看请求目标指纹、view/audio/control 能力
结束与撤销手动断开、超时、窗口关闭即清理

对端会话与权限

认证与能力协商已配对 peer、HMAC 票据、nonce/seq
对端本地批准独立批准屏幕 / 音频 / 控制权限
认证失败 / 未配对拒绝，不建立会话
权限拒绝保持离线或仅允许已批准能力

媒体与控制通道

建立自有媒体会话LAN host ICE、DTLS-SRTP、DataChannel
观看 / 音频 / 有限控制控制事件限速、序号、按键白名单
直连 / 编解码失败提示原因，降级为仅文本
输入不可用UIPI、锁屏、安全桌面、超时即撤销控制

清理与审计

审计与状态只记会话元数据，不记键盘内容或媒体 payload
立即撤销 control断开、锁屏或窗口关闭即失效

安全默认值

  • 配对码只做人机确认，不作为长期密钥
  • 远程控制默认关闭，能力独立批准
  • 禁止任意 shell、Win+L、Ctrl+Alt+Del、安全桌面
  • 仅局域网 host candidates，不引入公网中继
